<img width="1830" height="948" alt="image" src="https://github.com/user-attachments/assets/b1beb512-3586-4823-a60c-5709bde3def2" />🎬 Netflix-GPT – AI-Powered Movie Recommendation Platform

Netflix-GPT is a movie and show recommendation platform that leverages the power of Generative AI (GPT) to suggest content based on user prompts.

    Instead of typing a movie title, describe what you're in the mood for — and let GPT handle the rest!

🚀 Features

    🤖 AI-Powered Search – Enter prompts like “movies with time travel and suspense” to get personalized suggestions

    🧠 GPT Integration – Uses generative AI to understand user intent and return relevant movie/show results

    🎥 Netflix-Inspired UI – Clean, responsive interface inspired by Netflix’s design

    🔍 Prompt-Based Discovery – Search beyond titles using moods, genres, characters, or scenes

    🌗 Light & Dark Theme – Easily toggle between themes for visual comfort

🛠️ Tech Stack
Frontend

    React.js

    Tailwind CSS

AI Integration

    Groq GPT API
